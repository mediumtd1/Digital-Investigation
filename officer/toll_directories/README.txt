=======================================================
     PREMIUM TOLL PLAZA DIRECTORY TOOL
=======================================================

Welcome to the professional Toll Plaza Directory Tool. This 
project is designed with a "Plug & Play" architecture.

--- HOW TO INSTALL ---
1. Extract the zip file into your XAMPP 'htdocs' folder.
   (Example: C:\xampp\htdocs\toll_directories)
2. Open XAMPP Control Panel and START:
   - Apache
   - MySQL
3. Open your browser and go to: http://localhost/toll_directories/

The database and tables will be automatically created on your 
first visit. No manual setup is required.

--- ADMIN PANEL DETAILS ---
To manage, add, or delete toll records:
URL: http://localhost/toll_directories/EDIT.php

LOGIN CREDENTIALS:
- ID: admin
- PASSWORD: admin123

--- BULK IMPORT ---
You can upload an Excel/CSV sheet directly from the Admin Panel.
Ensure your CSV has columns in the following order:
Code, Name, Type, State, District, Concessionaire, Location (Lat,Lng).
